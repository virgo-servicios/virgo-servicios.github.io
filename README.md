# VST – Sitio web (diseño, fase 1)

Archivos estáticos (HTML + CSS puro, sin dependencias de build).

- `index.html` – página de inicio (adaptable de escritorio a móvil)
- `movil.html` – diseño específico de móvil (390 px) para referencia
- `assets/` – logo, sello, bandera y fotografías

## Publicar en GitHub Pages
1. Subir el contenido de esta carpeta a la raíz del repositorio (rama `main`).
2. Settings → Pages → Source: *Deploy from branch* → `main` / `(root)`.
3. Abrir `https://<usuario>.github.io/<repositorio>/`.
